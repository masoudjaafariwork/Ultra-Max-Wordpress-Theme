# راهنمای الترا مکس

الترا مکس یک قالب فروشگاهی فارسی برای وردپرس و ووکامرس است. قالب فقط ظاهر فروشگاه را می‌سازد. امکانات فروشگاه در افزونه‌های همراه آن است، پس اگر روزی قالب را عوض کنید، شماره مشتری‌ها، فاکتورها و تنظیمات فروش از بین نمی‌رود.

## محتوای بسته

| پوشه | چه چیزی |
| --- | --- |
| `themes` | قالب الترا مکس و قالب فرزند آن |
| `plugins` | چهار افزونه: هسته، ورود، فاکتور و سئو |
| `demos` | بسته‌های دمو برای نصب یک‌جا |
| `help.pdf` | همین راهنما |

## این نسخه

این نسخه، ساخت توسعه است. قالب و افزونه‌ها نصب و فعال می‌شوند، ولی امکانات فروشگاه در نسخه‌های بعدی اضافه می‌شود. این راهنما همراه هر نسخه کامل‌تر می‌شود.
