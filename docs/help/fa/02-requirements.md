# پیش‌نیازها

| مورد | حداقل |
| --- | --- |
| PHP | نسخه ۸٫۱ یا بالاتر |
| وردپرس | نسخه ۶٫۹ یا بالاتر |
| ووکامرس | یکی از سه نسخه اصلی آخر |
| المنتور | نسخه رایگان کافی است؛ المنتور پرو اختیاری است |

اگر PHP یا وردپرس سایت قدیمی‌تر باشد، افزونه‌ها فعال نمی‌شوند و در پیشخوان پیام روشنی نشان می‌دهند. سایت از کار نمی‌افتد.

نسخه PHP را از «ابزارها، سلامت سایت، اطلاعات» در پیشخوان ببینید.
