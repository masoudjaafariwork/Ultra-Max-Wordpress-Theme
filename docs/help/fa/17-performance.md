# کارایی

در «تنظیمات»، «کارایی»:

- **بارگذاری تنبل تصویر و ویدئو:** تصویرهای پایین صفحه فقط وقتی بار می‌شوند که بازدیدکننده به آن‌ها برسد.
- **پیش‌بارگذاری تصویر اصلی:** تصویر شاخص بالای نوشته زودتر از همه بار می‌شود.
- **پیش‌بارگذاری فونت متن:** متن از اول با فونت درست نمایش داده می‌شود.
- **CSS بحرانی درون صفحه:** استایل اصلی فروشگاه داخل خود صفحه قرار می‌گیرد تا صفحه بدون انتظار برای یک فایل نمایش داده شود.

کد فروشگاه الترا مکس به jQuery وابسته نیست و هر ماژول خاموش هیچ فایلی بار نمی‌کند.
