# جادوی راه‌اندازی

جادوی راه‌اندازی پس از اولین فعال‌سازی افزونه «الترا مکس: هسته» خودکار باز می‌شود. هر وقت خواستید می‌توانید آن را از منوی «الترا مکس»، «جادوی راه‌اندازی» دوباره باز کنید.

## مرحله‌ها

1. **خوش‌آمد:** معرفی کوتاه.
2. **افزونه‌های لازم:** ووکامرس و المنتور از مخزن وردپرس نصب و فعال می‌شوند. افزونه‌های ورود پیامکی، فاکتور و سئو داخل بسته هستند و فقط فعال می‌شوند. افزونه‌های اختیاری را می‌توانید خاموش بگذارید.
3. **انتخاب دمو:** پنج دمو را می‌بینید. درون‌ریزی دمو در نسخه بعدی اضافه می‌شود.
4. **لوگو و رنگ:** نام فروشگاه، لوگو و رنگ اصلی را انتخاب کنید.
5. **پایان:** به فروشگاه یا داشبورد بروید.

هر مرحله دکمه «رد کردن این مرحله» دارد. پیش از ذخیره لوگو و رنگ، از تنظیمات فعلی پشتیبان گرفته می‌شود.
