# ماژول‌ها

در منوی «الترا مکس»، «ماژول‌ها» هر امکان را روشن یا خاموش کنید. ماژول خاموش هیچ فایل CSS یا JS و هیچ کوئری اضافه‌ای بار نمی‌کند، پس سایت سبک‌تر می‌شود.

- کنار هر ماژول حجم فایل‌های آن به کیلوبایت آمده است.
- پیوند «تنظیمات» هر ماژول، همان بخش تنظیمات را باز می‌کند.
- با دکمه‌های «همه»، «فعال» و «غیرفعال» فهرست را فیلتر کنید.

ماژول‌های این نسخه: نوار اطلاع‌رسانی، دکمه‌های تماس شناور، دکمه بازگشت به بالا، کد سفارشی و کپی نوشته و برگه. ماژول‌های فروشگاه در نسخه‌های بعدی اضافه می‌شوند.
