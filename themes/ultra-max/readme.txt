A fast Persian WooCommerce storefront theme.

== Description ==

Ultra Max is a classic WordPress theme for Persian online stores. The theme holds presentation only; store features live in the Ultra Max plugins, so switching themes never loses customers, invoices or settings.

This is a development build. The storefront templates arrive in phase 2 of the roadmap.

== Installation ==

1. Upload the theme zip from Appearance > Themes > Add New > Upload Theme.
2. Activate it, then install the Ultra Max plugins that ship in the same package.
3. Put your own changes in the Ultra Max Child theme so updates never overwrite them.
