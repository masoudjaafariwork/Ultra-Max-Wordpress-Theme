# Logo

لوگوی فروشگاه: تصویر بارگذاری‌شده، یا نشان محصول همراه نام فروشگاه.

```php
UI::logo( array( 'name' => get_bloginfo( 'name' ), 'href' => home_url( '/' ), 'image_id' => 12 ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `name` | متن | لازم | نام فروشگاه؛ متن جایگزین تصویر |`n| `href` | نشانی | لازم | |`n| `image_id` | عدد | `0` | شناسه پیوست؛ ۰ یعنی نشان محصول |`n| `show_name` | بولی | وقتی تصویر نیست | |`n| `size` | `md`، `lg` | `md` | |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
