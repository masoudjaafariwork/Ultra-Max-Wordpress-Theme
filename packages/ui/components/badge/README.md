# Badge

برچسب کوتاه.

```php
UI::badge( array( 'children' => 'ویژه', 'tone' => 'brand' ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `children` | متن یا Html | لازم | |`n| `tone` | `neutral`، `brand`، `accent`، `success`، `warning`، `danger`، `info` | `neutral` | |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
