# EmptyState

پیام وسط صفحه وقتی چیزی برای نمایش نیست: ۴۰۴، جستجوی خالی و حالت تعمیر.

```php
UI::empty_state( array( 'code' => '404', 'heading' => 'h1', 'title' => 'پیدا نشد' ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `title` | متن | لازم | |`n| `icon` یا `code` | متن | — | |`n| `text` | متن | — | |`n| `heading` | `h2`، `h1` | `h2` | |`n| `children` | Html | — | دکمه‌ها و فرم |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
