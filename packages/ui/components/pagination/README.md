# Pagination

پیوند صفحه‌ها با قبلی و بعدی؛ ارقام با تنظیم ارقام فارسی می‌شوند.

```php
UI::pagination( array( 'label' => 'صفحه‌ها', 'current' => 2, 'total' => 9, 'base' => $base, 'previous' => 'قبلی', 'next' => 'بعدی' ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `label`، `previous`، `next` | متن | لازم | |`n| `current`، `total` | عدد | لازم | |`n| `base` | نشانی با `%#%` | لازم | |`n| `first` | نشانی | — | صفحه ۱ بدون `/page/1/` |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
