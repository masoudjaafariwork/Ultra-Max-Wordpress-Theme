# SiteFooter

پابرگ پیش‌فرض: لوگو و درباره، منو، تا چهار ستون ابزارک و خط حق نشر.

```php
UI::site_footer( array( 'logo' => $logo, 'copyright' => '© ۱۴۰۵' ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `logo` | Html | لازم | |`n| `copyright` | متن | لازم | |`n| `about` | متن | — | |`n| `menu` | Html | — | |`n| `columns` | فهرست Html | — | ستون‌های خالی حذف می‌شوند |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
