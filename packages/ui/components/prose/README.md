# Prose

تایپوگرافی محتوای ویرایشگر: تیترها، فهرست، نقل‌قول، جدول، کد، تصویر و چینش بلوک‌ها. ظاهر در `prose.css`.

```php
UI::prose( array( 'children' => Html::wp( $content ) ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `children` | Html | لازم | خروجی `the_content` |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
