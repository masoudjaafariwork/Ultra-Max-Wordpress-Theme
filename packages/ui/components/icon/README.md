# Icon

آیکون SVG درون‌خطی که برای همین پروژه روی شبکه ۲۴ پیکسلی کشیده شده است (منشأ در `design/ASSETS.fa.md`). تزئینی است و از صفحه‌خوان پنهان می‌ماند، پس دکمه یا پیوند دور آن باید نام دسترس‌پذیر داشته باشد.

```php
UI::icon( 'cart' )->print();
UI::icon( 'chevron-left', 'size-4 rtl:rotate-0' )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `$name` | نام آیکون | لازم | نام ناشناخته آیکون `info` را نشان می‌دهد. فهرست نام‌ها: `Icon::names()` |
| `$classes` | متن | `size-5` | فقط اندازه و جهت |

**آزمون:** کاتالوگ زنده و `tests/php/WidgetsTest.php`.
