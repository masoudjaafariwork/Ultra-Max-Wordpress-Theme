# BackToTop

دکمه بازگشت به بالا (CORE-12). پس از ۴۰۰ پیکسل پیمایش ظاهر می‌شود و تمرکز را به بالای صفحه می‌برد.

```php
UI::back_to_top( array( 'label' => 'بازگشت به بالا' ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `label` | متن | لازم | |`n| `target` | شناسه | `top` | |`n| `side` | `start`، `end` | `start` | |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
