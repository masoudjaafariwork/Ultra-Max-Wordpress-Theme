# Breadcrumbs

مسیر صفحه اصلی تا صفحه فعلی (CORE-08). آخرین مورد صفحه فعلی است و پیوند ندارد.

```php
UI::breadcrumbs( array( 'label' => 'مسیر راهنما', 'items' => $trail ) )->print();
```

| ورودی | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `label` | متن | لازم | |`n| `items` | فهرست `{label, href?}` | لازم | با کمتر از دو مورد چیزی چاپ نمی‌شود |

`class` در همه اجزا فقط کلاس چیدمان می‌پذیرد.
