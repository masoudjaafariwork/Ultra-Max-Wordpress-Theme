# الترا مکس

مونوریپوی توسعه قالب فروشگاهی الترا مکس و افزونه‌های همراه آن برای وردپرس و ووکامرس.

## وضعیت

این مخزن در ۱۸ آبان ۱۴۰۵ از صفر شروع شد. همه فایل‌ها و تصمیم‌ها از این نقطه به بعد فقط توسط Claude ساخته می‌شوند. پروژه در فاز ۰ است و هنوز کدی نوشته نشده است.
