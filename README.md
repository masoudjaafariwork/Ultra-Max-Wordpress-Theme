# الترا مکس

مونوریپوی توسعه قالب فروشگاهی الترا مکس و افزونه‌های همراه آن برای وردپرس و ووکامرس.

## وضعیت

این مخزن در ۱۸ آبان ۱۴۰۵ از صفر شروع شد. همه فایل‌ها و تصمیم‌ها فقط توسط Claude ساخته می‌شوند. فازهای ۰ (تحقیق و طراحی)، ۱ (زیرساخت مهندسی) و ۲ (هسته قالب و پنل) بسته شده‌اند. فاز بعدی فاز ۳ (سازنده چیدمان، سربرگ و صفحه اصلی) است.

## شروع

1. Node 24 و Docker Desktop لازم است.
2. یک بار: `npm ci`
3. هر بار: `npm run dev`، سپس http://localhost:8888 (پیشخوان: `admin` و `password`).

همه دستورها در بخش Commands فایل [CLAUDE.md](CLAUDE.md) است.
