# الترا مکس

مونوریپوی توسعه قالب فروشگاهی الترا مکس و افزونه‌های همراه آن برای وردپرس و ووکامرس.

## وضعیت

این مخزن در ۱۸ آبان ۱۴۰۵ از صفر شروع شد. همه فایل‌ها و تصمیم‌ها فقط توسط Claude ساخته می‌شوند. پروژه در فاز ۰ است و هنوز کد محصول نوشته نشده است. نمونه‌های طراحی آماده و تأییدشده‌اند.

## مستندات

- [نقشه راه](docs/ROADMAP.fa.md): هدف، معماری، فازها و نقش صاحب محصول.
- [کاتالوگ امکانات](docs/FEATURES.fa.md): ۳۲۵ قابلیت با شناسه، اولویت و منبع.
- [نمونه‌های طراحی](design/README.fa.md): سیستم طراحی و همه صفحات کلیدی به شکل HTML.
- [تحقیق بازار](docs/MARKET.fa.md): رقبا، قیمت‌ها، شکاف‌های بازار و قوانین مارکت‌پلیس‌ها.
- [پرامپت‌ها](docs/PROMPTS.fa.md): روش پیش بردن کار و پرامپت آماده هر فاز.
- [پیشرفت کار](docs/PROGRESS.fa.md): وضعیت فازها و قدم بعدی.
