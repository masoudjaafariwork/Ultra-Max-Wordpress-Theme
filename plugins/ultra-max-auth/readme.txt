== Description ==

One-time password login, SMS gateways and customer notifications.

Works with any theme. WooCommerce is optional.

This is a development build. Features arrive in later phases of the Ultra Max roadmap.

== Installation ==

1. Upload the plugin zip from Plugins > Add New > Upload Plugin.
2. Activate it.
